================================================================
NOTES FOR RAG RESOLUTION
================================================================

When asked "what audio name for X":
1. Return ONLY the audio name string — no soundset, no explanation
2. For mission_passed events → use a PLAY_MISSION_COMPLETE_AUDIO name from above
3. For mission_failed events → use FRANKLIN_LOSE_1 or MISSION_FAILED_JINGLE
4. For sting events → use a STING_* name
5. For ambient events → use an *_AMBIENCE name or DLC_ISLANDS_AMBIENCE_EXTERIOR

Example queries and correct answers:
Q: "mission_passed event: heist completion"          → HEIST_AWARD
Q: "mission_passed event: street race win"           → FRANKLIN_SMALL_01
Q: "mission_passed event: assassination"             → TREVOR_SMALL_01
Q: "mission_passed event: docks infiltration"        → MICHAEL_SMALL_01
Q: "mission_failed event: player killed"             → FRANKLIN_LOSE_1
Q: "mission_failed event: heist blown"               → STINGER_HEIST_FAIL_1
Q: "sting event: combat start"                       → STING_AGGRESSIVE_1
Q: "sting event: objective done"                     → STING_SUCCESS_1
Q: "ambient event: rainy night"                      → RAIN_AMBIENT
Q: "ambient event: airport"                          → AIRPORT_AMBIENCE
