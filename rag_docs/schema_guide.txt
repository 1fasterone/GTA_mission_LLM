GTA5 MISSION SCHEMA REFERENCE
Used by AnythingLLM RAG to answer schema structure questions.

=== TOP-LEVEL FIELDS ===
mission_name    string
location_name   enum: docks | airport | downtown | vinewood | sandy_shores | paleto_bay | alamo_sea | military_base | prison | port | highway
time_of_day     integer 0-23  (0=midnight, 6=dawn, 12=noon, 20=evening, 22=night)
weather         enum: clear | overcast | rain | thunder | foggy | smog
steps           array of MissionStep
peds            array of MissionPed
vehicles        array of MissionVehicle
objects         array of MissionObject
audio           array of MissionAudio

=== MissionStep ===
type   enum: go_to | kill_all | pickup | deliver | get_in_vehicle | escape | wait | checkpoint | race_lap | timer
label  string (shown on screen to player)
params dict  optional type-specific parameters (default {})

  go_to          player walks/drives to a waypoint
  kill_all       player eliminates all hostile peds
  pickup         player collects a spawned prop
  deliver        player reaches the delivery blip
  get_in_vehicle player boards a spawned vehicle
  escape         player loses all wanted stars
  wait           3-second pause with a message

  checkpoint     player passes through all checkpoints on a named track (single pass)
                 params: {"track": "airport.figure_8", "require_vehicle": true}
  race_lap       player completes N laps of a checkpoint circuit — USE FOR ALL RACING MISSIONS
                 params: {"lap_count": 5, "track": "airport.figure_8", "require_vehicle": true}
  timer          player survives / holds position for N seconds
                 params: {"seconds": 60}

=== MissionPed ===
description  string (plain English, resolved by RAG)
model        string (GTA5 ped model ID, filled by RAG)
role         enum: guard | patrol | target | civilian | ally
count        integer 1-8
weapon       enum: none | pistol | smg | rifle | shotgun | sniper

=== MissionVehicle ===
description  string (plain English, resolved by RAG)
model        string (GTA5 vehicle model ID, filled by RAG)
role         enum: patrol | escape | delivery | parked | chase | race_opponent
             race_opponent = spawns with an AI driver that heads toward first checkpoint
count        integer 1-4

=== MissionObject ===
description  string (plain English, resolved by RAG)
model        string (GTA5 prop model ID, filled by RAG)
role         enum: pickup | obstacle | decoration

=== MissionAudio ===
type     enum: ambient | mission_passed | mission_failed | sting
context  string (when this audio plays)
name     string (GTA5 audio name, filled by RAG)
