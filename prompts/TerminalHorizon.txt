TITLE: Terminal Horizon  
GENRE: High‑altitude freefall survival, 3D action, PC
STYLE: Stylized realism — roaring wind fields, sun‑bleached clouds, atmospheric scattering, contrail streaks, neon HUD.

CORE PREMISE
The player is an elite skydiver investigating a catastrophic mid‑air aircraft breakup over the Mojave corridor. Dropped from 30,000 ft with only a wingsuit, emergency chute, and a data‑capture visor, they must navigate turbulent air zones, recover black‑box fragments, evade rogue drones, and survive until touchdown. The vertical world spans five atmospheric layers, each implemented as separate Unity scenes.

SCENES (8 total)
MainMenu — animated title over drifting clouds, Start / Load / Quit

StratosGate — high‑altitude entry zone, thin air, contrail streaks, tutorial

JetstreamCorridor — violent crosswinds, cloud tunnels, first drone encounter

DebrisField — falling wreckage, black‑box fragments, high‑risk navigation

StormShelf — thunderheads, lightning arcs, boss drone encounter

FinalApproach — low‑altitude descent, wind shear, timed parachute deployment

GearBay — inventory and equipment management

LandingZoneEnding — ending cutscene: player touches down, rescue convoy arrives

NARRATIVE — Eight Story Beats
Drop Initiated — player exits aircraft (on_start)

Drone Shadow — silhouette passes through cloud layer (on_enter_zone)

Fragment Found — first black‑box shard recovered (on_pickup)

Velocity Warning — terminal velocity threshold exceeded (on_timer)

Drone Ambush — drone charges from cloud burst (on_enemy_death)

Storm Breach — player enters thunderhead interior (on_enter_zone)

Boss Dive — heavy combat drone guarding final fragment (manual)

Touchdown — player lands safely (on_enter_zone)

SCRIPTS — All Required Systems
WingsuitController (player)
3D freefall movement, drag curves, wind tunnels, dive/swoop transitions, turbulence impulses, parachute deployment

VelocityManager (custom)
speed tracking, terminal‑velocity thresholds, blackout vignette, recovery wobble, death on overspeed impact

GrappleGun (custom)
mid‑air ranged tool: charge, fire, retract; tether physics; attach to debris; swing momentum

DroneAI (enemy)
NavMesh‑in‑air: patrol → track → intercept → strike; reacts to player flare bursts; retreats when damaged

FlockBirds (custom)
boids‑style flocking for migrating birds; scatter on proximity or drone noise

SkyCamera (camera)
Cinemachine third‑person; wind‑lag follow; altitude‑based color grading; cloud‑density fog; roll‑tilt

GameManager (game_manager)
state machine (Menu/Playing/Paused/Downed/Win); score (fragments collected); lives (flare charges); scene transitions; save/load checkpoint

UIManager (ui_manager)
HUD: altitude meter, velocity bar, chute readiness indicator, fragment counter, overspeed pulse warning, pause panel, game‑over panel

AudioManager (custom)
spatial wind layers, jetstream rumble, cloud‑impact thumps, drone buzz, music crossfade by altitude band

HealthSystem (health)
player and drone HP, collision damage, death callbacks

FragmentCollectible (collectible)
pickup triggers story beat dialogue + score

WaypointNavigator (custom)
glowing flare beacon guiding next objective

InventoryManager (custom)
equipment slots: wingsuit mods, flare gun, grapple gun, chute upgrades

SaveLoadManager (saveload)
JSON checkpoint save between scenes

DialogueManager (dialogue_manager)
story beat subtitles + voice‑over triggers

AtmospherePalette (material_palette)
runtime sky/air color palette application

ProceduralCloudscape (level_generator)
volumetric cloud fields, debris clusters, storm cells
